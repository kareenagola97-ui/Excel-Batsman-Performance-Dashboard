# Excel-Batsman-Performance-Dashboard

Project Overview

This project analyzes batsman performance using Microsoft Excel. It demonstrates data analysis and dashboard creation using Excel's built-in features.

Tools

- Microsoft Excel

Excel Features Used

- Pivot Tables
- Pivot Charts
- Slicers
- Formulas (SUM, AVERAGE, MAX, MIN, IF)
- Conditional Formatting
- Dashboard Design

Dashboard Insights

- Total Runs
- Batting Average
- Strike Rate
- Highest Run Scorers
- Performance Comparison

Files

- Excel Dashboard Workbook
- Dashboard Screenshot
- Pivot Table Screenshot

Skills Demonstrated

- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development
- Excel Reporting

Conclusion

This project demonstrates practical Excel skills for analyzing sports performance data and presenting insights through an interactive dashboard.
